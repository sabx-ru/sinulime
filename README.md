# sinulime

An ongoing research project focused on understanding and documenting legacy PCU50 software interfaces, including **DDE/NCDDE** communication and the **MCVar** COM API.

## What we're working on

- Reverse engineering legacy components and comparing software versions.
- Investigating message formats, variable access, callbacks, and asynchronous behavior.
- Collecting runtime traces and validating findings against binary analysis.
- Building Python tools, test cases, and prototypes to make results reproducible.

## Repository

The `research_PCU50/` directory contains technical notes, evidence, experiments, analysis scripts, and verification results.

## Status

**Work in progress.** Findings are research-oriented and may change as additional evidence becomes available. This repository is not a production-ready implementation.
